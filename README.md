# 🟣 CircleCrop — Crop Gambar Profil Bulat

> Tool percuma untuk crop gambar profil jadi bulat cantik — dengan filter warna, border & preview saiz. Takde login, takde langganan.

![CircleCrop Preview](https://github.com/user-attachments/assets/402be5e2-439d-46d2-9c03-6f69f97b4290)

🔗 **Live Demo:** [crop-circle-image.netlify.app](https://crop-circle-image.netlify.app/)

---

## ✨ Features

- 🔵 **Crop Bulat** — upload gambar, seret & zum untuk adjust kedudukan
- 🎨 **Filter Warna** — 7 filter: Asal, B&W, Sepia, Warm, Cool, Vivid, Fade
- 🔵 **Border / Bingkai** — pilih tebal, warna, gaya (Solid / Putus / Gradien)
- 📐 **Pelbagai Saiz Output** — 400px, 512px, 800px, 1000px
- 👁️ **Preview Saiz** — tengok hasil 32px, 64px, 128px & output size serentak
- 💾 **Save PNG** — download terus, latar lutsinar (transparent)
- 📋 **Salin ke Clipboard** — paste terus ke mana-mana app
- 📱 **Mobile Friendly** — pinch zoom & swipe drag support

---

## 🚀 Cara Guna

1. Buka [crop-circle-image.netlify.app](https://crop-circle-image.netlify.app/)
2. Upload gambar (JPG / PNG / WEBP)
3. Seret gambar untuk adjust kedudukan
4. Scroll / pinch untuk zum
5. Pilih filter & border (optional)
6. Tekan **💾 Simpan PNG**

Siap. Dalam masa 10 saat. ✅

## 🌐 Deploy

Projek ini di-host di **Netlify** secara percuma.

Nak deploy sendiri:

```bash

git clone https://github.com/username/circlecrop.git

# Buka terus dalam browser
open index.html
```

Atau drag & drop folder ke [netlify.com/drop](https://netlify.com/drop) — siap!
